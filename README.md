# Peep — 3D Physics-Based Escape Game

A 3D physics-based escape game developed in Unity and C#, featuring
interactive puzzles and physics-driven object interactions.

## About

Peep is a 3D escape game where players explore an interactive
environment, manipulate physics-based objects and solve interconnected
puzzles to progress through the game.

Developed as my Computer Science Final Project at the
University of London.

## Key Features

- Physics-based object grabbing and manipulation
- Interactive environmental puzzles
- Player movement and first-person camera controls
- Puzzle progression and game-flow systems
- In-game clues and feedback
- Modular gameplay architecture

## Technical Implementation

- Built gameplay systems in C# using Unity
- Used raycasting to detect interactable objects
- Implemented physics interactions using Rigidbody and joint-based mechanics
- Organised gameplay logic into modular systems for player controls,
  puzzles, progression and feedback
- Used Cinemachine for camera behaviour

## Technologies

- Unity
- C#
- Unity Physics
- Cinemachine
- Blender

## Testing

Conducted playtesting with 10 participants to evaluate player controls,
physics interactions, puzzle feedback and UI usability.
